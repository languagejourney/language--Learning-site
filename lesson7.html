Capítulo 7: Verbos Irregulares (Yo Solo)

الدرس السابع: أفعال الضمير الأول فقط

هذه الأفعال تتميز بـ "شذوذ ذكي وخفيف جداً"؛ فهي تتغير بشكل خاص عندما تتحدث عن نفسك فقط (مع الضمير Yo).
مع باقي الضمائر الخمسة (Tú, Él/Ella, Nosotros, Vosotros, Ellos)، يرجع الفعل طبيعياً ومنتظماً 100%، ويأخذ نفس النهايات المنتظمة حسب مجموعته (AR, ER, IR).

1- الأفعال المنتهية بـ (go) مع الضمير Yo

عند تصريف الفعل مع (Yo)، ينتهي بطريقة خاصة بـ (go)، وباقي الضمائر تبقى طبيعية تماماً.

تطبيق عملي على فعل: Hacer (يفعل/يصنع) - ينتهي بـ ER
1- Yo hago (أنا أفعل / أصنع)
2- Tú haces (أنتَ تفعل)
3- Él / Ella / Usted hace (هو يفعل)
4- Nosotros / Nosotras hacemos (نحن نفعل)
5- Vosotros / Vosotras hacéis (أنتم تفعلون)
6- Ellos / Ellas / Ustedes hacen (هم يفعلون)
تطبيق عملي على فعل: Salir (يخرج) - ينتهي بـ IR
1- Yo salgo (أنا أخرج)
2- Tú sales (أنتَ تخرج)
3- Él / Ella / Usted sale (هو يخرج)
4- Nosotros / Nosotras salimos (نحن نخرج)
5- Vosotros / Vosotras salís (أنتم تخرجون)
6- Ellos / Ellas / Ustedes salen (هم يخرجون)
أفعال شائعة جداً تتبع نفس هذا النمط (ينتهي بـ go مع Yo):
  • 1- Poner (يضع) -> Yo pongo / Tú pones
  • 2- Traer (يجلب / يحضر) -> Yo traigo / Tú traes
  • 3- Oír (يسجل / يسمع) -> Yo oigo / Tú oyes
2- الأفعال المنتهية بـ (zco) مع الضمير Yo

هذه الأفعال تنتهي في أصلها بـ (cer) أو (cir) وقبله حرف متحرك "حرف علة" تقلب النهاية تلقائيًا مع الضمير Yo الى (zco)، بينما تعود طبيعية ومنتظمة 100% مع باقي الضمائر.

تطبيق عملي على فعل: Conocer (يعرف أشخاص أو أماكن) - ينتهي بـ ER
1- Yo conozco (أنا أَعرف)
2- Tú conoces (أنتَ تعرف)
3- Él / Ella / Usted conoce (هو يعرف)
4- Nosotros / Nosotras conocemos (نحن نعرف)
5- Vosotros / Vosotras conocéis (أنتم تعرفون)
6- Ellos / Ellas / Ustedes conocen (هم يعرفون)
تطبيق عملي آخر على فعل: Conducir (يقود / يسوق) - ينتهي بـ IR
1- Yo conduzco (أنا أقود)
2- Tú conduces (أنتَ تقود)
3- Él / Ella / Usted conduce (هو يقود)
4- Nosotros / Nosotras conducimos (نحن نقود)
5- Vosotros / Vosotras conducís (أنتم تقودون)
6- Ellos / Ellas / Ustedes conducen (هم يقودون)
أفعال شائعة جداً تتبع نفس هذا النمط (ينتهي بـ zco مع Yo):
  • 1- Traducir (يترجم) -> Yo traduzco / Tú traduces
  • 2- Producir (ينتج) -> Yo produzco / Tú produces
  • 3- Ofrecer (يعرض / يقدم خدمة) -> Yo ofrezco / Tú ofreces

ملاحظة تنبيهية: الأفعال التي تنتهي بـ (cer) أو (cir) وتكون مسبوقة بـ حرف ساكن (Consonant) بدلاً من حرف متحرك — مثل فعل Vencer (ينتصر) أو Convencer (يقنع) — تتغير مع الضمير Yo إلى zo فقط وليس zco (مثال: Yo venzo / Yo convenzo)، وذلك للحفاظ على صوت حرف الـ C اللطيف.

3- الأفعال المنتهية بـ (jo) مع الضمير Yo

تنطبق هذه القاعدة على الأفعال التي تنتهي بـ (ger) أو (gir). مع الضمير Yo، يتحول حرف g إلى j للحفاظ على الصوت الخفيف للكلمة (صوت الـ "خ")، ثم ترجع بقية الضمائر منتظمة بحرف الـ g الأصلي:

  • 1- Elegir (يختار): Yo elijo | Tú eliges
  • 2- Coger (يأخذ / يمسك): Yo cojo | Tú coges
  • 3- Recoger (يجمع / يستلم): Yo recojo | Tú recoges
  • 4- Exigir (يتطلب / يطالب): Yo exijo | Tú exiges
4- الأفعال المنتهية بـ (gu) والمنتهية بـ (go) بدون u

الأفعال التي تنتهي بـ (guir) تُحذف منها الـ u عند التصريف مع Yo فقط حتى لا يتغير نطق الحرف:

  • 1- Conseguir (يحصل على): Yo consigo | Tú consigues
  • 2- Seguir (يتابع / يستمر): Yo sigo | Tú sigues
  • 3- Distinguir (يميز): Yo distingo | Tú distingues
5- الأفعال المنتهية بـ (oy) مع الضمير Yo

مجموعة صغيرة وخاصة جداً من الأفعال اليومية الشائعة ينتهي تصريفها مع Yo بالنهاية oy:

  • 1- Dar (يعطي): Yo doy | Tú das
  • 2- Estar (يكون - للمؤقت/المكان): Yo estoy | Tú estás
  • 3- Saber (يعلم / يعرف معلومة): Yo sé (تغيير فريد بالكامل مع Yo) | Tú sabes
  • 4- Ver (يرى): Yo veo | Tú ves
