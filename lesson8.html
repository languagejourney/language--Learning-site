Capítulo 8: Verbos Totalmente Irregulares

الدرس الثامن: الأفعال الشاذة بالكامل

هذه الأفعال تتغير بشكل كامل ومباشر في جذرها ونهاياتها مع جميع الضمائر، ولا تلتزم بأي من القواعد المنتظمة، وتُحفظ كما هي لشدة أهميتها واستخدامها اليومي.

1- فعل: Ir (يذهب)

يتغير شكل الفعل بالكامل عند التصريف ليتحول إلى حرف الـ V:

1- Yo voy (أنا أذهب)
2- Tú vas (أنتَ تذهب)
3- Él / Ella / Usted va (هو يذهب)
4- Nosotros / Nosotras vamos (نحن نذهب)
5- Vosotros / Vosotras vais (أنتم تذهبون)
6- Ellos / Ellas / Ustedes van (هم يذهبون)
2- فعل: Ser (يكون)

يكون - الهوية / الصفات الدائمة / الجنسية. من أهم أفعال الإسبانية وتتغير صيغته تماماً بدون اتباع نهايات مجموعته:

1- Yo soy (أنا أكون)
2- Tú eres (أنتَ تكون)
3- Él / Ella / Usted es (هو يكون)
4- Nosotros / Nosotras somos (نحن نكون)
5- Vosotros / Vosotras sois (أنتم تكونون)
6- Ellos / Ellas / Ustedes son (هم يكونون)
3- فعل: Haber (مساعد / الوجود)

يُستخدم كفعل مساعد للتركيبات القواعدية، أو بصيغته الشائعة (Hay) للتعبير عن الوجود:

1- Yo he
2- Tú has
3- Él / Ella / Usted ha (تتحول إلى Hay عند التعبير عن "يوجد")
4- Nosotros / Nosotras hemos
5- Vosotros / Vosotras habéis
6- Ellos / Ellas / Ustedes han
4- فعل: Tener (يمتلك / لديه)

تتغير صيغة الفعل بالكامل مع معظم الضمائر، حيث يتغير جذر الكلمة مع Yo بـ go، وتتحول الـ e إلى ie مع باقي الضمائر:

1- Yo tengo (أنا أمتلك / عندي)
2- Tú tienes (أنتَ تمتلك)
3- Él / Ella / Usted tiene (هو / هي تمتلك)
4- Nosotros / Nosotras tenemos (نحن نمتلك)
5- Vosotros / Vosotras tenéis (أنتم تمتلكون)
6- Ellos / Ellas / Ustedes tienen (هم يمتلكون)
5- فعل: Venir (يأتي)

يشبه تصريف فعل Tener تماماً، حيث تتغير e إلى ie في الوسط مع شذوذ Yo بـ go:

1- Yo vengo (أنا آتي)
2- Tú vienes (أنتَ تأتي)
3- Él / Ella / Usted viene (هو / هي يأتي)
4- Nosotros / Nosotras venimos (نحن نأتي)
5- Vosotros / Vosotras venís (أنتم تأتون)
6- Ellos / Ellas / Ustedes vienen (هم يأتون)
